# Nexus 签到 · 每日一点

> 一块手表上的「每日一点」小应用 —— 每天抬腕就有一点新内容，顺手把签到也做了。

竖向滑动换屏，**10 屏**内容：**每日签到 + 幸运大转盘 / 每日一句 / 每日诗词 / 历史上的今天 / 每日英语 /
每日简报 / 每日黄历 / 我的 / 关于 / 实用工具**。
点「实用工具」进入 **10 个实用工具**（独立页面，竖向滑动浏览）——
**天气 / 翻译 / 世界时间 / 假期倒计时 / 微博热搜 / 汇率 / 电影票房 / Epic 喜加一 / 技术日历 / 今天吃什么**，
全部实时联网、抬腕即用。
背景是一张内置图（轻量级手表的图片只能随应用打包，不支持运行时联网换图），支持旋转表冠翻屏。

支持设备：**华为轻量级智能手表**（Lite Wearable，API 12 / HarmonyOS 5.0 及以上，圆形/方形屏自适应）。

## 安装

到本仓库 [Releases](../../releases) 页下载最新版本 zip，解压得到 `.app` 安装包。

- 用 **华为开发者工具 / DevEco Studio** 签名后安装到手表；或
- 已配好签名环境时直接用命令行：`hdc app install <文件>`

> 包是**未签名**的，需要你自己的开发者证书签名后才能装到手表上。

## 首次使用：绑定你的账号

应用需要一次「绑定账号」才能用签到 / 转盘 / 头像这些跟服务器有关的功能。
绑定方式是把你的账号凭证（Token）交给作者，作者会给你打一个**已绑定好**的专属包：

1. 打开 [如何获取 Token](docs/如何获取Token.html)（手机浏览器打开，支持一键复制），按里面说明从网站取到你的 Token
2. 把 Token 和你的昵称私聊发给作者
3. 收到专属包后按上面「安装」步骤装上，打开就是你的账号

> 为什么要这样：手表没有键盘，而登录网站需要过人机验证，在手表上完成不了。
> 打包注入是唯一稳妥的方式，也**不需要你在手表上输入任何东西**。
> 出于安全考虑：**Token 等于账号钥匙，只发给你信任的人，别发群、别发帖、别截图**。

## 常见问题

**Q：内容不更新 / 显示「获取失败」？**
网络没通或者接口临时抽风。应用会自动重试，也可以进入对应屏点「换一个 / 换一批」手动刷新。

**Q：背景图会变吗？**
不会。轻量级手表系统的图片只能随应用打包安装，无法在运行时联网换图，
这是系统限制（官方文档：图片在编译阶段被编译为位图并打包）。

**Q：实用工具需要联网吗？**
需要。天气 / 翻译 / 世界时间 / 假期 / 热搜都是实时联网查询；断网时会提示「获取失败」，
点「刷新」重试即可。

**Q：签到提示「Token 无效或已过期」？**
Token 过期了。重新走一遍上面「绑定账号」的流程即可。

**Q：能不能在手表上直接输入账号密码登录？**
不行，原因见上面「为什么要这样」——网站的登录有人机验证，手表上无法完成。
