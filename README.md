# Nexus 签到 · 每日一点

> 一块手表上的「每日一点」小应用 —— 每天抬腕就有一点新内容，顺手把签到也做了。

竖向滑动换屏，**8 屏**内容：**每日签到 + 幸运大转盘 / 每日一句 / 每日诗词 / 更多内容 / 今日黄历 /
我的 / 关于 / 实用工具**。
其中三个入口会进入**独立页面**（竖向滑动浏览）：

- **更多内容**：每日英语 / 历史上的今天 / 每日简报（页内切换）
- **今日黄历**：公历 + 农历 + 干支 + 生肖 + 宜忌 + 节气 + 节假日 + 星座 + 月相 + 运势
- **实用工具**：**10 个工具** —— 天气 / 翻译 / 世界时间 / 假期倒计时 / 微博热搜 / 汇率 /
  电影票房 / Epic 喜加一 / 技术日历 / 今天吃什么，全部实时联网、抬腕即用

背景是一张内置图（轻量级手表的图片只能随应用打包，不支持运行时联网换图），支持旋转表冠翻屏。

支持设备：**华为轻量级智能手表**（Lite Wearable，API 12 / HarmonyOS 5.0 及以上，圆形/方形屏自适应）。

- 🔤 **翻译**：中英互译，用应用自带键盘打字（手表没有系统输入法），自动判断方向
- 🌍 **世界时间**：北京 / 东京 / 伦敦 / 纽约 实时时间，一眼看时差

- 📶 **网络失败自动兜底**：任何内容取不到时都保留上一次 / 内置内容，界面不会空

## 配套手机 App（Nexus 发送端）

手表没有键盘、网站的登录又有人机验证，所以「拿到 Token」这一步交给手机做：

**它做什么**

1. 在手机里**打开网站登录**（系统浏览器内核，人机验证正常过）
2. 一键**取出登录凭证（Token）**
3. 把 Token 通过**局域网**发给手表 —— 手机屏幕上会直接显示「手表要填的地址」
4. 手表端填一次地址即可，之后随时自己取

**怎么用**

1. 手机安装 `Nexus发送端.apk`（本页 Release 附件，已签名，直接安装）
2. 手机与手表连**同一个网络**（同一路由器，或用手表连手机热点）
3. 打开 App → 登录 → 点「抓取 Token」→ 点「开启共享」，记住屏幕上显示的地址
4. 手表进入「我的 → 输入 Token → 改地址」，填入那个地址，返回后确认即可

> 不需要 root、不需要电脑、Token 只在你的手机和手表之间传递。

## 安装

**手表端**：到本仓库 [Releases](../../releases) 页下载最新版本 zip，解压得到安装包。

- 用 **DevEco Studio** 打开工程、配置自己的开发者证书后签名安装；或
- 已配好签名环境时直接命令行：`hdc install <hap 文件>`

> 包是**未签名**的，需要你自己的开发者证书签名后才能装到手表上。

**手机端（发送端）**：Release 附件里的 `Nexus发送端.apk` 已用发布证书签名，传到手机直接安装即可
（首次安装需在系统里允许「安装未知来源应用」）。

> ⚠️ 如果手机上装过更早的调试版，请**先卸载**再装正式版（签名不同，无法覆盖安装）。

## 首次使用：绑定你的账号

应用需要一次「绑定账号」才能用签到 / 转盘这些跟服务器有关的功能。**现在自己就能搞定**：

1. 手机装好并打开 **Nexus 发送端**（见上节），登录你的账号
2. 点「抓取 Token」→「开启共享」，记下屏幕上显示的地址
3. 手表进「我的 → 输入 Token → 改地址」，填刚才那个地址，返回后点确认
4. 手表提示取件成功后，昵称 / 等级 / 积分就会自动显示

> 手表端也保留了**手动输入 Token**（自研键盘 + 拼音选字）的方式，两条路任选。
> 出于安全考虑：**Token 等于账号钥匙，别发给别人、别发群、别截图**。

## 常见问题

**Q：内容不更新 / 显示「获取失败」？**
网络没通或者接口临时抽风。应用会自动重试，也可以进入对应屏点「换一个 / 换一批」手动刷新。

**Q：手表上点「实用工具 / 更多内容 / 今日黄历」进不去？**
先确认装的是**最新版本**。早期版本这三个页面因体积超出系统快照上限会打不开，最新版已修。

**Q：取件时提示「连不上」？**
按顺序检查：手机 App 是否点了「开启共享」→ 手机和手表是否在同一网络 →
手表里填的地址是否和手机显示的一致（手机会话关了地址会变，重新看一下即可）。

**Q：背景图会变吗？**
不会。轻量级手表系统的图片只能随应用打包安装，无法在运行时联网换图，
这是系统限制（官方文档：图片在编译阶段被编译为位图并打包）。

**Q：签到提示「Token 无效或已过期」？**
Token 过期了，重新走一遍上面「首次使用」的流程即可。

**Q：能不能在手表上直接输入账号密码登录？**
不行，网站的登录有人机验证，手表上无法完成 —— 所以才有发送端 App 这个中转。
