# 如何获取自己的 Token（手机图文教程 · 全浏览器版）

> 适用：想在手表上使用「签到 / 幸运大转盘」，需要用网站 **ws.fseatech.cn** 的 Token 把账号关联起来。
> 本文面向**只用手机**的朋友，不管你是 Chrome、Edge、Via、Firefox 还是 Safari，都有对应步骤。

---

## ⚠️ 先看这一条，比什么都重要

**Token = 你账号的一把钥匙。**

拿到它的人，就能替你操作账号（签到、抽奖、兑换、改资料）。所以：

- ❌ 不要发到群里
- ❌ 不要发帖、不要截图露出来
- ✅ 只私聊发给需要的人（比如帮你打包应用的作者）

本教程的脚本只做一件事：**把你浏览器里已有的 Token 显示出来**，不会上传、不会发到任何地方。

---

## 一、Token 是什么？长什么样？

| 问题 | 答案 |
|---|---|
| 是什么 | 你在网站登录后，网站发给你的一张「临时通行证」 |
| 干嘛用 | 手表上的签到 / 抽奖凭它证明「是你本人」在操作 |
| 长什么样 | 一长串字母数字，一般以 `eyJ` 开头，几百个字符，**没有空格、没有换行** |
| 有效期 | 会过期。过期后重新登录、重新取一次即可 |
| 一人一个 | 是。Token 和账号绑定，不能共用 |

---

## 二、⚠️ 先记住这个「90% 的人卡在这里」的坑

**手机上和电脑上不一样！**

| | 电脑 | 手机 |
|---|---|---|
| 点书签 | 点一下书签栏上的书签 → 直接执行 ✅ | **从「书签 / 收藏夹」菜单里点 → 不会执行 ❌** |
| 正确姿势 | 同上 | **点浏览器的「地址栏」→ 输入书签的名字 → 点下面跳出来的带 ★ 的提示** ✅ |

**手机浏览器（Chrome / Edge 等）有个特性：从书签菜单点书签，它不知道你当前在看哪个网页，所以脚本不执行，看起来就是「点了没反应」。必须走地址栏。**

**另外一个好消息**：手机书签有长度限制（约 2KB～8KB），本教程给的代码是 **1645 个字符**，在安全范围内，不用担心粘不下。

## 三、先花 30 秒，测一下你的浏览器行不行

不用猜，直接测。

### 第 1 步：随便收藏一个页面
打开任意网页（比如就停在 `ws.fseatech.cn`），点浏览器菜单 → **☆ 添加书签 / 添加到收藏**。

### 第 2 步：把它改成一个「测试书签」

打开书签管理 → 找到刚存的那个 → **编辑**：
- 名称改成：`测试`
- **网址里原有的内容全部删掉**，粘贴这一行：

```
javascript:alert('书签脚本可用')
```

保存。（细节操作看下面的「按浏览器分步骤」）

### 第 3 步：在任意网页上调用它
**点「地址栏」→ 输入 `测试` → 下面跳出一条带 ★ 的建议 → 点它。**

- ✅ **弹出一个提示框「书签脚本可用」** → 你的浏览器可以，继续往下做。
- ❌ **什么都没发生** → 这个浏览器不支持，看下面这张表换一个。

### 各浏览器支持情况

| 浏览器 | 能用吗 | 说明 |
|---|---|---|
| **Chrome（安卓）** | ✅ 可以 | 必须用「地址栏输入名字」的方式调用 |
| **Edge（安卓）** | ✅ 可以 | 和 Chrome 同一个内核，方式完全一样 |
| **Firefox（安卓）** | ✅ 可以 | 地址栏输入名字点建议；从书签里点也行 |
| **三星浏览器** | ✅ 一般可以 | 书签管理里能编辑，地址栏调用 |
| **Via 浏览器** | ✅ 可以 | 支持 `javascript:` 书签；它还有个「脚本管理」功能更省事（见方法三） |
| **夸克 / UC / QQ浏览器** | ⚠️ 不确定 | 部分版本会拦截 `javascript:`。测不过就换 Edge / Chrome / Firefox |
| **微信 / QQ 里点开的网页** | ❌ 不行 | 那是内置浏览器，没有书签功能。点右上角「⋯」→「在浏览器打开」，换真正的浏览器 |
| **iPhone 上的 Safari / Edge / Chrome / Firefox** | ✅ 走 Safari 那套 | iPhone 上所有浏览器都是同一内核，**Safari 不行就别换浏览器了**，直接看方法二 |

> 顺手一提：测不过也不用折腾，**方法二（电脑）永远能用**，而且不需要是同一台设备，只要登录同一个账号即可。

## 四、方法一：手机书签脚本（只有手机的朋友走这条）

原理一句话：**把一小段代码存成一个书签**，在网站上调用它，它就把你的 Token 弹出来给你复制。设置一次，以后每次只要点一下。

### 第 1 步：先登录网站

1. 打开手机浏览器，访问 **ws.fseatech.cn**
2. 输入邮箱和密码登录
3. **确认「我的」页面显示的是你的账号**（没登录就一定取不到）

### 第 2 步：随便收藏一个页面

就停在 ws.fseatech.cn 上，点浏览器菜单 → **☆ 添加书签 / 添加到收藏**。名字先随便起。

### 第 3 步：按你的浏览器，把它改成「取 Token 的钥匙」

#### 🟦 Chrome（安卓）
1. 点右上角 **⋮** → **书签**
2. 找到刚存的书签，**长按它** → 选 **修改 / 编辑**
3. **名称**改成 `获取Token`
4. **网址**里原内容全部删掉 → 粘贴附录里的整段代码
5. 保存

#### 🟦 Edge（安卓）
1. 点底部（或右上角）的 **⋯** 菜单 → **收藏夹**
2. 找到刚加的收藏，点 **⋯** / 长按 → **编辑**
3. **名称**改成 `获取Token`
4. **URL** 框里原内容全部删掉 → 粘贴附录里的整段代码
5. 保存

#### 🦊 Firefox（安卓）
1. 点 **⋮** → **书签 / Bookmarks**
2. 长按刚存的书签 → **编辑**
3. 名称改成 `获取Token`，**地址**全部替换成附录里的代码
4. 保存

#### 🌐 三星浏览器
1. **≡** → **书签** → 长按刚存的书签 → **编辑**
2. 名称 `获取Token`，地址替换成附录代码 → 保存

#### 🚀 Via 浏览器
1. 点右下角/右上角 **☰ / ⋮** → **书签**
2. 点 **+** 新建书签（或长按已有书签 → 编辑）
3. 标题填 `获取Token`，**网址**粘贴附录里的整段代码 → 保存

#### 🍎 iPhone（Safari 及所有 iPhone 浏览器）
1. 点底部中间的 **分享** 图标（方框 + 向上箭头）
2. 选 **添加书签**，保存到 **「收藏夹」**（Favorites）里
3. 点底部 **书本** 图标 → 收藏夹 → 找到它 → **编辑**
4. 名称 `获取Token`；**网址**全部删掉 → 粘贴附录代码 → **完成**

### 第 4 步：调用它，取 Token

**安卓（关键！不要从书签菜单点）**
在 ws.fseatech.cn 的页面上 → **点地址栏** → 输入 `获取Token`（或只打「获取」两个字）→
地址栏下方出现一条带 ★ 的书签建议 → **点它**。

**iPhone**
在 ws.fseatech.cn 的页面上 → **点地址栏** → 在下方收藏夹里点 **获取Token**。

屏幕会弹出一个黑底面板，里面就是你的 Token。

### 第 5 步：复制

1. 点面板里的 **【一键复制】**
2. 如果没反应，就**长按**框里的内容 → 选 **全选** → **复制**
3. 点 **【关闭】** 回到网页

搞定 ✅ 以后 Token 过期了，重登录 → 再点一次这个书签就行。

### 第 6 步：拿到 Token 之后怎么用？

先**把 Token 存进手机备忘录**（别发群、别发帖）。然后二选一：

**方式一（推荐）· 自己填进手表**
1. 打开发好的手表应用，**一直往下滑到最后一屏「我的」**
2. **在屏幕上点一下** → 会自动打开手表上的键盘
3. 把 Token 输进去（手表键盘用法：**点字母**；**长按 q～p 出数字**；**左右滑动**切换小写/大写/符号）
4. 点右上角的 **✓ 确认** → 自动保存，以后每次打开 App 都一直在

**方式二 · 让作者帮你打包**
把 Token **私聊**发给作者，作者会给你一份已经绑定好账号的安装包。
装好后「我的」屏会显示你的昵称，对得上就说明绑定成功 ✅

> Token 会过期。等手表提示「未登录」时，回网站重新登录 → 重新取一次 → 在手表上重新填一遍即可。

## 五、方法二：用电脑取（最省事，手机搞不定时的万能兜底）

**不需要和手机同一台设备**，电脑浏览器登录同一个账号就行。

### 路线 A：开发者工具（最直观）

1. 电脑上打开 **Chrome** 或 **Edge**，访问 ws.fseatech.cn 并登录
2. 按 **`F12`** 键（或右键 → **检查 / Inspect**）
3. 上方选 **`Application`**（中文版叫 **「应用」**）标签
   （窗口太窄看不到就点 **`>>`** 展开）
4. 左侧依次展开：**Storage（存储）** → **Local Storage（本地存储）** → 点 **`https://ws.fseatech.cn`**
5. 右侧出现一张 Name / Value 的表
6. 找到 Name 是 **`token`** 的那一行 → **双击**右边的值 → **全选复制**

### 路线 B：一行命令（更快，推荐）

1. 同样按 `F12` 打开开发者工具
2. 选 **`Console`**（控制台）标签
3. 粘贴这一行，按回车：

```
copy(localStorage.token)
```

4. Token 就**自动进剪贴板**了，直接去粘贴。

> 如果提示 `undefined`，说明没登录成功或登录已过期 —— 回网站重新登录一次。

## 六、方法三：Via 浏览器的「脚本管理」（安卓，比书签更省事）

Via 这类浏览器自带**脚本管理**，可以指定「在哪些网址上跑这段代码」，用起来比书签顺手：

1. Via → 菜单 → **设置** → 找到 **更多 / 高级工具** → **脚本管理**
2. 点 **+** → **新建脚本**
3. 名称填 `获取Token`
4. **匹配网址** 填 `*`（表示所有网站都生效；懒得配就先这么写，用完删掉）
5. 代码区粘贴附录里的代码（**去掉开头的 `javascript:`**，只要后面那段）
6. 保存 → 回到 ws.fseatech.cn 页面刷新一下，就会弹出 Token 面板

（不同 Via 版本的菜单名字略有差别，找不到就在设置里搜「脚本」。）

## 七、常见问题

**Q1　点了书签没反应，页面一点变化都没有？**
按可能性从高到低查：
1. **你是不是从「书签菜单」里点的？** 手机必须**从地址栏输入书签名字**去点（见第二节）。
2. 代码没粘完整，或者开头的 `javascript:` 被浏览器吃掉了 → 重新编辑，核对开头。
3. 浏览器不支持 → 回第三节测一下，或换个浏览器（Edge / Chrome / Firefox）。

**Q2　弹出「没有找到 Token」？**
说明你当前没有登录态。回网站**重新登录一次**，成功后再点书签。
注意：别在**无痕 / 隐身窗口**里操作，无痕窗口一关数据就没了。

**Q3　手表提示「未登录」，或以前能用现在不能了？**
Token 过期了。重新登录网站 → 重新取一次 → 换掉旧的。

**Q4　换手机 / 清了浏览器数据 / 换了浏览器？**
Token 会丢，重新登录、重新取一次就行。

**Q5　这个 Token 会不会被盗号？**
Token 就等于钥匙，**拿到的人能操作你的账号**。不要发群、不要发帖、不要公开截图；要发给开发者帮打包时**私聊发**。如果担心，去网站改一次密码通常能作废旧凭证。

**Q6　一个 Token 能不能几个人一起用？**
不能。Token 跟账号绑定，一人一个。

**Q7　在微信 / QQ 里打开的网页能不能操作？**
不能，那是内置浏览器，没有书签功能。点右上角 **⋯ → 在浏览器打开**，再用真正的浏览器走前面的步骤。

**Q8　iPhone 上试了 Safari 不行，换成 Edge / Chrome 会好一点吗？**
不会。iPhone 上所有浏览器都强制使用同一套内核，限制是一样的。iPhone 用户建议直接走**方法二（电脑）**。

## 八、附录：书签脚本代码（整段复制）

复制下面**整段**（从 `javascript:` 到最后的分号，一行，不要漏头尾，共 1645 个字符）：

```
javascript:!function(){var t='';try{t=localStorage.getItem('token')||''}catch(e){}if(!t){try{for(var i=0;i<localStorage.length;i++){var v=localStorage.getItem(localStorage.key(i));if(typeof v=='string'&&v.indexOf('eyJ')==0){t=v;break}}}catch(e){}}if(!t)return alert('没找到 Token。请先在网站上登录成功，再点一次本书签。');var d=document.createElement('div');d.setAttribute('style','position:fixed;left:0;top:0;right:0;bottom:0;z-index:99999;background:#111318;color:#fff;padding:16px;font-family:sans-serif;overflow:auto');d.innerHTML='<div style="font-size:17px;font-weight:bold;margin-bottom:10px">你的 Token</div><textarea id="nx" style="width:100%;height:34vh;font-size:13px;padding:8px;border-radius:8px;border:1px solid #333;background:#1b1e24;color:#fff"></textarea><div style="font-size:13px;color:#ff9090;margin-top:10px;line-height:1.7">Token 等于账号钥匙，别发群、别发帖、别截图。</div><button id="nxc" style="width:100%;margin-top:12px;padding:14px;font-size:17px;border:0;border-radius:8px;background:#0ea5a5;color:#fff">一键复制</button><button id="nxq" style="width:100%;margin-top:8px;padding:12px;font-size:16px;border:1px solid #444;border-radius:8px;background:transparent;color:#ccc">关闭</button>';document.body.appendChild(d);var a=document.getElementById('nx');a.value=t;document.getElementById('nxc').onclick=function(){a.focus();a.select();var o=!1;try{o=document.execCommand('copy')}catch(e){}if(o)return alert('已复制，去粘贴吧');if(navigator.clipboard)navigator.clipboard.writeText(t).then(function(){alert('已复制，去粘贴吧')},function(){alert('复制失败，请长按框里的文字手动复制')});else alert('复制失败，请长按框里的文字手动复制')};document.getElementById('nxq').onclick=function(){d.parentNode.removeChild(d)}}();
```

> 这段代码做什么：读你浏览器本地存的 `token`，用一个黑色面板展示出来并提供复制按钮。
> 它**不会**把 Token 发送到任何服务器。
