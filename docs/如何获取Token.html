如何获取自己的 Token

手机全浏览器教程 · 手表签到 / 幸运大转盘需要它来关联你的账号 · 网站：ws.fseatech.cn

⚠️ 先看这一条，比什么都重要

Token 就是你账号的一把钥匙。拿到它的人，就能替你操作账号（签到、抽奖、兑换、改资料）。

  • 不要发到群里、不要发帖、不要截图露出来
  • 只私聊发给需要的人（比如帮你打包应用的作者）
  • 本教程的脚本只做一件事：把你自己浏览器里已有的 Token 显示出来，不会上传、不会发到任何地方。

一、Token 是什么？长什么样？

问题答案
是什么你在网站登录后，网站发给你的一张「临时通行证」
干嘛用手表上的签到 / 抽奖，凭它证明「是你本人」在操作
长什么样一长串字母数字，一般以 eyJ 开头，几百个字符，没有空格、没有换行
有效期会过期。过期后重新登录、重新取一次就行
能共用吗不能。Token 跟账号绑定，一人一个

二、⚠️ 手机上的一个坑，90% 的人卡在这里

手机和电脑不一样，调用书签的方式不同：

怎么调用
电脑点书签栏上的书签 → 直接执行 ✅
手机从「书签 / 收藏夹」菜单里点 → 不会执行 ❌
正确：点浏览器的「地址栏」→ 输入书签的名字 → 点下面跳出来的带 ★ 的提示 ✅

原因：手机浏览器从书签菜单点书签时，不知道你当前在看哪个网页，所以脚本不执行，看起来就是「点了没反应」。

顺便一个好消息

手机书签有长度限制（约 2KB～8KB）。本教程给的代码是 1645 个字符，在安全范围内，不用担心粘不下。

四、方法一：手机书签脚本（只有手机的朋友走这条）

原理一句话：把一小段代码存成一个书签，在网站上调用它，它就把你的 Token 弹出来给你复制。设置一次，以后每次只要点一下。

1
先登录网站

打开手机浏览器访问 ws.fseatech.cn，输入邮箱和密码登录。确认「我的」页面显示的是你的账号（没登录就一定取不到）。

2
随便收藏一个页面

就停在 ws.fseatech.cn 这个页面上，打开浏览器菜单 → ☆ 添加书签。名字先随便起。

3
按你的浏览器，把它改成「取 Token 的钥匙」

Chrome（安卓）

  1. 点右上角 ⋮ → 书签
  2. 找到刚存的书签，长按它 → 选 修改 / 编辑
  3. 名称改成 获取Token
  4. 网址里原内容全部删掉 → 粘贴附录里的整段代码
  5. 保存

Edge（安卓）

  1. 点下方/右上角的 ⋯ 菜单 → 收藏夹
  2. 找到刚加的收藏 → 点 ⋯ 或长按 → 编辑
  3. 名称改成 获取Token
  4. URL 框里原内容全部删掉 → 粘贴附录代码
  5. 保存

Firefox（安卓）

  1. 点 ⋮ → 书签 / Bookmarks
  2. 长按刚存的书签 → 编辑
  3. 名称 获取Token，地址全部替换成附录代码 → 保存

三星浏览器

  1. ≡ → 书签 → 长按刚存的书签 → 编辑
  2. 名称 获取Token，地址替换成附录代码 → 保存

Via 浏览器

  1. 点右下角 / 右上角 ☰ 或 ⋮ → 书签
  2. 点 + 新建书签（或长按已有书签 → 编辑）
  3. 标题填 获取Token，网址粘贴附录里的整段代码 → 保存

Via 用户还可以看下面的方法三，比书签更省事。

iPhone（Safari 及所有 iPhone 浏览器）

  1. 点底部中间的 分享 图标（方框 + 向上箭头）
  2. 选 添加书签，保存到 「收藏夹」（Favorites）里
  3. 点底部 书本 图标 → 收藏夹 → 找到它 → 编辑
  4. 名称 获取Token；网址全部删掉 → 粘贴附录代码 → 完成
4
调用它，取 Token

安卓（关键：不要从书签菜单点）
在 ws.fseatech.cn 的页面上 → 点地址栏 → 输入 获取Token（或只打「获取」两个字）→ 地址栏下方出现一条带 ★ 的书签建议 → 点它。

iPhone
在 ws.fseatech.cn 的页面上 → 点地址栏 → 在下方收藏夹里点 获取Token。

屏幕会弹出一个黑底面板，里面就是你的 Token。

5
复制
  • 点面板里的 【一键复制】
  • 如果没反应，就长按框里的内容 → 选 全选 → 复制
  • 点 【关闭】 回到网页

搞定 ✅ 以后 Token 过期了，重新登录 → 再点一次这个书签就行。

6
拿到 Token 之后怎么用？

先把 Token 存进手机备忘录（别发群、别发帖）。然后二选一：

方式一（推荐）· 自己填进手表

  1. 打开发好的手表应用，一直往下滑到最后一屏「我的」
  2. 在屏幕上点一下 → 会自动打开手表上的键盘
  3. 把 Token 输进去（手表键盘用法：点字母；长按 q～p 出数字；左右滑动切换小写 / 大写 / 符号）
  4. 点右上角的 ✓ 确认 → 自动保存，以后每次打开 App 都一直在

方式二 · 让作者帮你打包

把 Token 私聊发给作者，作者会给你一份已经绑定好账号的安装包。装好后「我的」屏会显示你的昵称，对得上就说明绑定成功 ✅

Token 会过期。等手表提示「未登录」时，回网站重新登录 → 重新取一次 → 在手表上重新填一遍即可。

五、方法二：用电脑取（最省事，手机搞不定时的万能兜底）

不需要和手机同一台设备，电脑浏览器登录同一个账号就行。

路线 A：开发者工具（最直观）

  1. 电脑上打开 Chrome 或 Edge，访问 ws.fseatech.cn 并登录
  2. 按 F12 键（或右键 → 检查 / Inspect）
  3. 上方选 Application（中文版叫 应用）标签（窗口太窄看不到就点 >> 展开）
  4. 左侧依次展开：Storage（存储） → Local Storage（本地存储） → 点 https://ws.fseatech.cn
  5. 右侧出现一张 Name / Value 的表
  6. 找到 Name 是 token 的那一行 → 双击右边的值 → 全选复制

路线 B：一行命令（更快，推荐）

  1. 同样按 F12 打开开发者工具
  2. 选 Console（控制台）标签
  3. 粘贴下面这一行，按回车
copy(localStorage.token)

Token 就会自动进剪贴板，直接去粘贴。若提示 undefined，说明没登录成功或登录已过期，回网站重新登录一次。

六、方法三：Via 浏览器的「脚本管理」（安卓，比书签更省事）

Via 这类浏览器自带 脚本管理，可以指定「在哪些网址上跑这段代码」，用起来比书签顺手：

  1. Via → 菜单 → 设置 → 找到 更多 / 高级工具 → 脚本管理
  2. 点 + → 新建脚本
  3. 名称填 获取Token
  4. 匹配网址 填 *（表示所有网站都生效；懒得配就先这么写，用完删掉）
  5. 代码区粘贴附录里的代码（去掉开头的 javascript:，只要后面那段）
  6. 保存 → 回到 ws.fseatech.cn 页面刷新一下，就会弹出 Token 面板

不同 Via 版本的菜单名字略有差别，找不到就在设置里搜「脚本」。

七、常见问题

Q1　点了书签没反应，页面一点变化都没有？

按可能性从高到低查：

  1. 你是不是从「书签菜单」里点的？手机必须从地址栏输入书签名字去点（见第二节）。
  2. 代码没粘完整，或开头的 javascript: 被浏览器吃掉了 → 重新编辑，核对开头。
  3. 浏览器不支持 → 回第三节测一下，或换个浏览器（Edge / Chrome / Firefox）。
Q2　弹出「没有找到 Token」？

说明你当前没有登录态。回网站重新登录一次，成功后再点书签。
注意：别在无痕 / 隐身窗口里操作，无痕窗口一关数据就没了。

Q3　手表提示「未登录」，或以前能用现在不能了？

Token 过期了。重新登录网站 → 重新取一次 → 换掉旧的。

Q4　换手机 / 清了浏览器数据 / 换了浏览器？

Token 会丢，重新登录、重新取一次就行。

Q5　这个 Token 会不会被盗号？

Token 就等于钥匙，拿到的人能操作你的账号。不要发群、不要发帖、不要公开截图；要发给开发者帮打包时私聊发。如果担心，去网站改一次密码通常能作废旧凭证。

Q6　一个 Token 能不能几个人一起用？

不能。Token 跟账号绑定，一人一个。

Q7　在微信 / QQ 里打开的网页能不能操作？

不能，那是内置浏览器，没有书签功能。点右上角 ⋯ → 在浏览器打开，再用真正的浏览器走前面的步骤。

Q8　iPhone 上 Safari 不行，换成 Edge / Chrome 会好一点吗？

不会。iPhone 上所有浏览器都强制使用同一套内核，限制是一样的。iPhone 用户建议直接走方法二（电脑）。
