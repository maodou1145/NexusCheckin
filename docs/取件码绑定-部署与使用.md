# 取件码绑定 · 部署与使用

> **一句话**：用户在浏览器把 Token 投递到「信箱」，拿到 **4 位取件码**；
> 手表「我的 → 取件码绑定」输入这 4 位数字即可完成绑定。
> 取件码 **10 分钟有效、只能取一次、取走即刻销毁**。

---

## 🅰 路线 A：局域网直连（零部署，先用这条）

**不需要任何服务器、不需要 4 位码**，PC 和手表在同一局域网即可。

### PC 侧（双击即可，已做好一键脚本）

| 双击 | 作用 |
|---|---|
| `tools\get-token.bat` | 打开浏览器让你登录 `ws.fseatech.cn`（过滑块）→ 自动把 Token 存到 `tools/.token.txt` |
| `tools\lan-share.bat` | 把 Token 通过局域网共享出去（**窗口要一直开着**，会打印一个网址和 Token 长度） |

> 也可以命令行跑（注意用带 playwright 的 Python）：
> ```
> "C:\Program Files\PyManager\python.exe" tools/get-token.py
> "C:\Program Files\PyManager\python.exe" tools/lan-share.py
> ```
> ⚠️ 直接敲 `python` 可能指向别的 Python（本机 PATH 里第一个是 WorkBuddy 自带运行时，没有 playwright）。

### 手表侧

1. DevEco 里 Run 到手表
2. 「我的」→ 点底部 **【取件码绑定】有码输码，没码直接确认**
3. 键盘页**什么都不输，直接点「确认」**
4. 屏幕应显示 **`取件成功 ✓ N 字符`** —— 这个 N 要和 PC 上 `lan-share.bat` 打印的长度**一致**

### 前提与验证点（真机实测过一半）

- ✅ 已实测通过：手表能访问 PC 的内网 IP、**lite 允许明文 http**（config.json 无需额外配置）
- ⚠️ PC 第一次跑 `lan-share.bat` 若弹防火墙询问，**选「允许」**
- ⚠️ 手表若走**蓝牙共享手机网络**（而非自己连 Wi-Fi），可能访问不到 PC 的内网 IP
- ⚠️ PC 的 IP 会变 → 跑 `lan-share.bat` 看它打印的地址，填进 `pages/pick/index.js` 顶部的 `LAN_API`

### 常见提示对照

| 屏幕显示 | 含义 |
|---|---|
| `取件成功 ✓ 238 字符` | 成功（238 示例，实际以你的 Token 为准） |
| `Token 太短（N 字符）` | 服务端那边给的不是真 Token（先确认跑过 `get-token.bat`） |
| `连不上 (code xxx)` | 网络不通：同网段？防火墙？`LAN_API` 地址对不对？ |
| `没配置取件地址` | `pages/pick/index.js` 的 `LAN_API` 没填 / 包没重新 Run |

## 🅱 路线 B：云端取件码 · 部署（作者一次性操作，约 20 分钟）

### 1. 注册 uniCloud 并创建服务空间

1. 打开 https://unicloud.dcloud.net.cn/ 用 DCloud 账号登录（没有就注册，需实名）
2. 创建一个**免费版服务空间** —— ⚠️ **选哪个云厂商有讲究（官方定价页实查）：**

| 云厂商 | 有没有免费版 | 说明 |
|---|---|---|
| **支付宝云** | ✅ 有 1 个 | **推荐**：免费额度最宽松（云数据库 读 62 万 RU/月、写 31 万 WU/月），且**没有**阿里云的「小时级最低消费」规则 |
| 阿里云 | ✅ 有 1 个 | 额度偏紧：读 **500 次/天**、写 **300 次/天**；且 2026-03-16 起云函数按「单函数+小时」**最低消费 0.01 元**（折算 90 GBs），免费额度 1000 GBs/月 ÷ 90 ≈ 只够 **11 个"有调用的小时"**，我们这种分散调用容易吃完 |
| 腾讯云 | ❌ **没有** | 入门版 **99 元/月起**，别选 |

> ⚠️ **两个免费空间都有「有效期默认 1 个月、到期需手动续期」**（到期前 15 天可续，
> 不续期会被**停服并释放**）→ 记个每月提醒；嫌麻烦可升基础版（支付宝云 4.5 元/月 / 阿里云 5 元/月）。

### 2. 创建云函数 `nxbox`

1. 进入服务空间 → 左侧【云函数】→ **新建云函数**
2. 云函数名称填 **`nxbox`**
3. 把仓库里 `tools/box-server/index.js` 的内容**整段粘贴**进云函数的 `index.js`
4. `tools/box-server/package.json` 的内容粘进云函数的 `package.json`（无第三方依赖）
5. 保存 → 上传部署

### 3. 创建数据库集合

【云数据库】→ 新建集合，名字填 **`nx_box`**
（阿里云即使不建、首次写入也会自动创建，但建议手动建，权限选「仅创建者可读写」即可——
本云函数用管理端权限访问，不受影响）

### 4. 配置云函数 URL 化

1. 【云函数】→ 找到 `nxbox` → **详情** → 配置**访问路径**：`/nxbox`
2. 保存后得到访问地址，形如：
   `https://xxx-xxxxxxxx-xxxxxx.bspapp.com/nxbox`
3. 自测一下（把域名换成你的）：
   ```bash
   curl -X POST "https://你的域名/nxbox/put" -H "content-type: application/json" -d "{\"token\":\"test-token-string-1234567890\"}"
   # 期望：{"ok":true,"code":"1234","ttl":600}
   curl "https://你的域名/nxbox/get?code=1234"
   # 期望：{"ok":true,"token":"test-token-string-1234567890"}
   # 再查一次同一个码 → 应变成 {"ok":false,"msg":"取件码不存在或已被使用"}（一次性生效）
   ```

### 5. 把地址填进两个地方

| 位置 | 填什么 |
|---|---|
| 手表工程 **`pages/pick/index.js` 顶部**的 `BOX_API` | 上面那个地址（**结尾不带斜杠**） |
| 生成页面 `tools/box-web/index.html` 里的 `BOX_API` | 同一个地址 |

### 6. 托管「生成取件码」页面

任选其一：
- **uniCloud 前端网页托管**（推荐，同一控制台里就有）
- 任何静态托管 / 自己的服务器（纯静态单文件，无依赖）

把 `tools/box-web/index.html` 传上去，得到用户可访问的网址（例如 `https://你的域名/token.html`）。
**记得先改好里面的 `BOX_API` 再上传。**

### 7. 构建手表端

```bash
python tools/sync-to-h.py
# H 盘构建 + 签名（见 DEVELOPMENT.md 的构建配方）
```
构建前确认 `pages/pick/index.js` 顶部的 `BOX_API` 已在 G 盘源码里填好（这样 H 盘构建区也会带上）。

## 二、用户怎么用（写进给用户的说明）

1. 手机或电脑浏览器打开**取件码页面**
2. 登录 `ws.fseatech.cn`（页面里有「复制书签代码」按钮，手机用户按教程存成书签取 Token）
3. 把 Token 粘进输入框 → 点**生成取件码** → 得到 **4 位数字**（10 分钟内有效）
4. 手表滑到「**我的**」→ 点底部「**取件码绑定**」→ 输入这 4 位数字 → 确认
5. 手表自动取回 Token 并绑定，「我的」页会显示 Token 剩余天数

## 三、要花钱吗？（按实际用量算账）

**结论：这个功能的用量极小，免费版远远够用，不用花钱。**

单次绑定（一个用户绑一次）产生的消耗：

| 资源 | 单次消耗 | 免费额度（支付宝云免费版） | 能撑多少次 |
|---|---|---|---|
| 云函数调用 | 2 次（put + get） | 1.5 万次/月 | ~7500 次绑定/月 |
| 云函数资源量 | 约 0.1~0.3 GBs | 1000 GBs/月 | 数千次 |
| 数据库写 | 2 次（存入 + 删除） | 31 万 WU/月 | 十几次万 |
| 数据库读 | 1 次 | 62 万 RU/月 | 数十万次 |
| 出网流量 | ~2 KB | 1 GB/月 | 约 50 万次 |
| 页面托管（生成页） | 一个 ~8KB 的 HTML | CDN 1 GB/月 | 约 12 万次访问 |

**换算成人话**：就算有 100 个用户、每人每月换 3 次 Token（= 300 次绑定/月），
也只用到免费额度的 **百分之几**。真正需要花钱只有两种情况：

1. 免费空间**每月手动续期**嫌麻烦 → 升基础版（支付宝云 4.5 元/月、阿里云 5 元/月）
2. 想要**自定义域名**（更好看、更稳）→ 域名本身 ~30-60 元/年 + 需在对应云厂商接入备案

**一分钱不花的替代**：如果连每月续期都不想管，可以用「GitHub 仓库 + jsdelivr」形态
（手表输用户名，token 存在用户自己的公开仓库里，全程零服务零运维）——
代价是用户需要有 GitHub 账号，喵。

## 四、安全设计（如实说明）

| 环节 | 措施 |
|---|---|
| 传输 | 全程 HTTPS |
| 存放 | Token 只存 **10 分钟**，取件成功即刻从数据库删除 |
| 一次性 | 同一个取件码取过一次即销毁，重复取返回「不存在或已被使用」 |
| 防爆破 | 4 位码（1 万组合）+ 10 分钟窗口 + **单码最多试 5 次**即作废 |
| 过期清理 | 每次调用顺手删除过期记录 |
| 与旧方案对比 | 比「私聊把 Token 发给作者」更规范：短时、可自取、不经过聊天记录 |

⚠️ 仍然需要注意：**Token 等于账号钥匙**，用户不要把 Token 或取件码转发、截图。

## 五、排错

| 现象 | 原因 / 处理 |
|---|---|
| 手表提示「没配置取件地址」 | `pages/pick/index.js` 顶部的 `BOX_API` 没填 → 填好重新构建 |
| 页面点生成报「页面还没配置服务器地址」 | `box-web/index.html` 里的 `BOX_API` 没改 |
| 页面报「网络失败」 | 检查 URL 化地址是否可访问；浏览器控制台看跨域错误 |
| 手表提示「取件码不存在或已被使用」 | 取件码已用过或输错；让用户重新生成 |
| 手表提示「取件码已过期」 | 超过 10 分钟，重新生成 |
| 手表提示「尝试次数过多」 | 同一码错 5 次后作废，重新生成 |
| 云函数报 `uniCloud is not defined` | 代码必须跑在 uniCloud 云函数里（不是普通 Node） |

## 六、相关文件

  `tools/get-token.bat` / `tools/lan-share.bat`
