NexusCheckin · 取件码

把账号 Token 投递进来，拿到 4 位取件码，在手表上输入即可绑定。
取件码 10 分钟有效、只能取一次，取走即刻销毁。
1登录网站并取出 Token
· 电脑：打开 ws.fseatech.cn 登录 → 按 F12 → Console → 粘贴 copy(localStorage.token) 回车（自动复制）。
· 手机：用教程里的「书签脚本」取 Token（点下面按钮复制书签代码）。
2粘贴 Token
3在手表上输入这个取件码
----
取件码拿到后请尽快在手表上输入，10 分钟后失效；输入过一次就作废。
🔐 Token 等于账号钥匙：本页只把它临时存 10 分钟供你手表取回，取走立刻删除。 不要把 Token 或取件码发给别人、不要截图。
